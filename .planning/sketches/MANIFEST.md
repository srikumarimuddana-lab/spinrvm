# Spinr — Sketch Manifest

## Design Direction

**Grounded Trust** — warm, honest, clarity-first. The Spinr brand speaks to a Canadian community where drivers keep 100% of the fare and riders see exactly what they pay. The UI must feel respectful of both user groups, not like a surveillance or control tool. Dark-first mobile (drivers work nights; maps are dark). High-contrast money display (earnings motivate drivers). State-aware UI throughout — every screen communicates context.

## Reference Points

- Lyft driver app: clean state communication, generous spacing
- Monzo banking app: trust through radical transparency of money
- Waze: map-centric, driver-appropriate information hierarchy
- Transit app: clarity over density, functional but warm

## Design Principles

1. **Driver dignity** — 0% commission deserves a UI that treats drivers as business owners
2. **Fare transparency** — riders see every line item before confirming
3. **State clarity** — every user always knows what mode they are in
4. **Safety accessible** — SOS / emergency always within 2 taps
5. **Thumb-zone first** — primary actions at the bottom of every mobile screen
