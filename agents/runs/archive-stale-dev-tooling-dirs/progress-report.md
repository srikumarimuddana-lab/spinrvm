### Candidate approaches

**Approach A — doc-only fix scoped to the two living directory-status tables (CLAUDE.md + AGENTS.md).** Since the directories are already gone, the only real work left is correcting the two current, actively-read guidance docs that still claim otherwise: root `CLAUDE.md`'s "Claude-Adjacent Directories" table and `AGENTS.md`'s duplicate "Codex-Adjacent Directories" table (same rows, same wording, Codex-facing copy of the same doc). Tradeoff: small, fast, low-risk diff — but it deliberately leaves several *dated* audit artifacts (`docs/claude-audit-2026-04-22.md`, `docs/claude-audit.json`, `docs/audit/15_TECH_STACK_AND_FILE_MAPPING.md`, `docs/audit/daily/2026-04-11.md`, and two `reports/audits/2026-07-22-*.md` files) still describing `memory/`/`discovery/` as open findings (`P2-001: OPEN` in the JSON).
