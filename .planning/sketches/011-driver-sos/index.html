Design Decision Summary
A — Visible SOS Button
Maximally discoverable and fast. But a full-screen red alarm is visible to any passenger in the back seat — the exact scenario where a driver most needs help. Trades discretion for speed in a context where discretion is non-negotiable. Suitable for a solo use case (breakdown, medical), not a threat-from-passenger scenario.
B — Hardware Shortcut
Zero screen visibility to the passenger — the most discreet option. But reliability is device-dependent (iOS vs Android volume key behaviour varies), discoverability requires onboarding, and there's no way to offer a 911 call path from a hardware gesture. A strong secondary mechanism, not a primary one.
C — Discreet Hold Shield ← Winner
Dual-mode: hold (3s) for the silent discreet path, tap for the full overlay when safe. The ring progress and tiny badge confirm the alert went through without any visible alarm. Right-thumb placement means the driver never takes their hand off a natural position. Discreet mode is the default and is clearly labelled so drivers understand what will happen before an emergency occurs.
