> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: Railway build context is repo root — Railway uses `dockerfilePath: backend/Dockerfile` from railway.json but with the **repo root** as the Docker build context. This means `backend/.dockerignore` is never applied. Only a `.dockerignore` at the repo root is respected. **A root .dockerignore was created in commit a6d2b684.**

- [ ] CONSTRAINT: pydantic-settings reads .env at import time — `rate_limiter.py` imports and runs at module load, before any env var injection logic. Use `os.environ.get()` directly (as `redis_client.py` does) rather than `settings.RATE_LIMIT_REDIS_URL` for Redis URLs that must be read from container env vars. **Fixed in commit a6d2b684.**

**Do not proceed until all boxes are checked.**
