## Pre-publication notes

1. **Do not publish a ® symbol unless a trademark registration has actually
   been granted** — using ® for an unregistered mark is itself a
   misrepresentation in most jurisdictions. Confirm with counsel/CIPO
   filing status first; default to ™ if unsure.
2. If Spinr operates only in Saskatchewan today but plans expansion, note
   that Canadian trademark registration is federal (via CIPO), not
   provincial — this doesn't need to wait for multi-province operation.
