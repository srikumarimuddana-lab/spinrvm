Design Decision Summary
A — Table-First
Scales well for bulk auditing. Fails the 30-second constraint — every approval requires full page navigation and a separate document viewer. Good for ops oversight dashboards, not triage queues.
B — Card Queue
Eliminates page navigation. Status visible at-a-glance. But the expand/collapse pattern hides action buttons until the card opens — adding friction. Difficult to process multiple drivers quickly.
C — Triage Panel ← Winner
Pins the approve action above the fold — visible without any scroll. Urgency dots in the queue signal which applications are overdue. Zero navigation; click a row, dossier loads instantly. Clean applications can be approved in ~22 seconds.
