## What's NOT resolved (the OtpScreen issue)

**Symptom:** Both rider-app and driver-app crash IDENTICALLY on OtpScreen render:
```
[Error: Element type is invalid: expected a string (for built-in components) or
a class/function (for composite components) but got: undefined.]
```

App boots, reaches OtpScreen, render fails, ErrorBoundary catches. App stays alive but auth flow is dead.

**Differential test confirmed:** issue is in shared code/deps, NOT app-specific (Stripe, Firebase Auth, etc. ruled out).

**Top hypotheses (ranked):**
1. **`@expo/vector-icons@15.1.1` Ionicons** — TTF asset import may resolve to undefined under RN 0.85.2 + Bridgeless. OtpScreen uses `<Ionicons>` 6+ times.
2. **`CustomAlert` (`shared/components/CustomAlert.tsx`)** — uses Modal internally; even though Modal is patched, CustomAlert wrapper might have its own issue.
3. **`Animated.View` or `KeyboardAvoidingView`** — RN 0.85.2 codegen edge case beyond ActivityIndicator/Modal.

The diagnostic at HEAD logs `typeof` of every import — output will identify the culprit definitively.
